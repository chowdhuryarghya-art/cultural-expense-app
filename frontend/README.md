# Frontend

The frontend is a React, TypeScript, and Vite application. For full project
setup, database migrations, features, and screenshots, see the
[project README](../README.md).

Run frontend commands from this directory:

```powershell
npm ci
npm run dev
```

The development server runs at <http://localhost:5173>. The frontend expects
the backend API at <http://localhost:3000>.

Available scripts:

- `npm run dev` — start the Vite development server.
- `npm run build` — type-check and create a production build in `dist/`.
- `npm run lint` — run ESLint.
